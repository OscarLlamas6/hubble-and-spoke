# yq

## ¿Qué es?

Un procesador de YAML en línea de comandos (`mikefarah/yq`), equivalente a `jq`.

## ¿Qué problema resuelve?

Extraer o filtrar documentos YAML con `grep`/`awk` es frágil. `yq` entiende la estructura.

## Conceptos clave

| Término | Definición |
|---|---|
| **Expresión** | Ruta y filtros, como `.spec.replicas`. |
| **`select()`** | Filtra documentos o elementos. |
| **`eval-all`** | Procesa todos los documentos juntos. |
| **`strenv()`** | Lee una variable de entorno de forma segura. |

## Cómo se usa en este POC

Solo en los tests: [scripts/unit-test.sh](../../scripts/unit-test.sh) extrae el claim y el `Provider` de los archivos reales, y [tests/lib/field.sh](../../tests/lib/field.sh) inspecciona el render. Versión fijada en [versions.env](../../versions.env) y descargada a `.bin/`.

## Comandos útiles para inspeccionar / debuggear

```bash
source scripts/env.sh
yq 'select(.kind == "WebApp")' crossplane/examples/webapp-claim.yaml
task crossplane:render | yq 'select(.kind == "Object") | .spec.forProvider.manifest.kind'
```
